操作说明：从购买到客户端下载与连接

购买与获取机场订阅

在跑路云官方网站注册账号，选择基础版、旗舰版或团队版完成支付后即时开通。进入用户中心复制专属订阅链接，该链接包含当前套餐可用节点，可在客户端中一键导入并自动更新。

Windows 推荐 Clash 系或 v2rayN，macOS 推荐 Clash 系或 Surge，Android 推荐 Clash Meta 或 v2rayNG，iOS 推荐 Shadowrocket、Stash 等。Linux 可使用兼容内核客户端。请从各软件官方发布渠道获取安装包，跑路云官网仅提供订阅与使用说明，不捆绑来源不明的安装文件，以降低安全风险。

导入订阅并开始加速

安装客户端后选择从 URL 导入，粘贴官网订阅地址并更新节点列表。按延迟排序后选择 IPLC 或当前最优节点，开启系统代理或 TUN 模式即可。建议配置分流：国内直连、境外走代理。更换设备时只需重新导入同一订阅。遇到连接问题可查看日志或通过官网工单反馈节点名称。

常见问题（FAQ）

跑路云官方客户端应该从哪里下载？如何确认是正版？

请通过本跑路云(Paoluz)官方网站的操作说明了解推荐客户端，并前往对应软件的官方发布页或应用商店获取。不要从不明网盘下载安装包。安装后使用官网用户中心的订阅链接导入，即可匹配您的套餐权限与节点。

不同套餐的设备数量限制如何理解？

基础版最多 3 台设备同时在线，旗舰版 5 台，团队版 20 台。同时在线指同一时刻保持连接的终端数量。可在用户中心查看并断开旧设备。需要更多终端时升级至团队版即可。

流量用尽后服务会中断吗？年付用户有额外流量吗？

当月额度用尽后新连接将受限，次月自动重置。年付仅为价格优惠，流量仍按自然月计算且不结转。使用中可随时在官网升级套餐并补差价，更高额度立即生效。

为什么有的节点看视频很卡或游戏丢包？该如何选择？

请优先使用套餐对应线路：基础版走普通节点池，旗舰与团队可选用 IPLC 游戏优化与原生流媒体节点。在客户端开启延迟测试并更新分流规则。若持续异常，通过工单提交节点名称，官方将协助排查。

支持退款吗？如何联系官方客服？

虚拟加速服务开通后一般不支持无理由退款。若因线路长期故障无法使用，可通过官网工单协商。旗舰版享有优先工单，团队版配备专属客户经理。提交时请附上账号与问题描述。

订阅链接安全吗？可以给家人朋友一起用吗？

订阅链接绑定账户流量与设备额度，请勿公开分享。家庭或小团队请按设备数量选择对应套餐并自行管理在线终端。官网支持重置订阅链接以增强安全性。
